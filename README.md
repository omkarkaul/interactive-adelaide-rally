# Interactive Adelaide Rally

This is a vibecoded interactive map of the Adelaide Rally for 2026. I have recently become a big fan of quickly standing up small web tools like this with Claude.

Being a fan of the rally for years, and intending to finally spectate it this year in 2026, I noticed the official website [documents the stages](https://www.adelaiderally.com.au/road-closures) for each day in a somewhat naive way. I thought it would be wonderful to be able to view it all in a single place, interactively.  

Going forward, I would love to add provenance for both historical stages and the years to come, a pace notes scrubber, and many other fun features.
